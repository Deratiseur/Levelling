## English

### Description

This mod lets you change the class XP table. You can grant the same XP table to all classes (your choice) AND/OR grant the XP table you want to the class you want.

These tables are based on infinite XP (capped at 8 million XP).

Warning: install Levelling Changer AFTER any mod that changes XP to infinite XP (e.g. after Tweak Anthology).

On IWDEE, you MUST install "the same table for everyone" for it to work. After the general table, you can of course install individual tables.
